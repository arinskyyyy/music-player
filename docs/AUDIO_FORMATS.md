# Audio Formats & Streaming Compatibility

Supported Formats:
- MP3 (MPEG Audio Layer III)
- WAV (Waveform Audio)
- OGG (Ogg Vorbis)
- FLAC (Free Lossless Audio Codec)
- M4A (MPEG-4 Audio)

Local files are read using the browser `FileReader` API and `URL.createObjectURL` without uploading to any remote server, preserving privacy.
