# SyncRoom Theming Engine

SyncRoom features a custom theme engine:
1. **Base Mode**:
   - `bw`: Pure retro black & white contrast.
   - `system`: Follows system dark/light mode preference.
2. **Website Accent Color**:
   - Pre-configured pixel presets: White, Cyan, Violet, Amber, Emerald, Rose.
   - Custom hex color picker.
3. **Text Color Presets**:
   - Pure White, Soft Silver, Ice Cyan, Lemon, Mint, Blush.
4. **Custom Pixel Cursor**:
   - Crisp SVG pixel-art pointer cursor for retro gaming aesthetic.
